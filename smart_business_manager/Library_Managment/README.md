 Library Management System

Project Overview

A Python-based Library Management System using SQLite database.

This application helps manage library books, student book issues, and returns.

Features

* Add New Books
* View All Books
* Search Books by ID
* Update Book Copies
* Delete Books
* Issue Books to Students
* Return Books
* Automatic Book Availability Tracking
* SQLite Database Storage
* Input Validation and Error Handling

Technologies Used

* Python
* SQLite
* SQL
* sqlite3
* pathlib

Concepts Practiced

* Functions
* CRUD Operations
* SQL Queries
* Database Relationships
* Foreign Keys
* INSERT, SELECT, UPDATE, DELETE
* fetchone() and fetchall()
* Exception Handling
* While Loops
* Conditional Statements

python library.py
